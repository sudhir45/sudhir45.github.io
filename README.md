# sudhir.is-a.dev

Personal cybersecurity blog and portfolio.

Essays, topic archives, talks, and Cyberdle, built with Astro. The design, Folio, sets the site as a magazine: Source Serif 4 with real italics, Inter, and JetBrains Mono on warm paper, with light and dark themes and motion that respects a reader's settings.

Talks are listed newest first, with optional custom covers and a slide viewer for each presentation.
